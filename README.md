# Gestor de Tarefas

Gestor de tarefas simples no terminal feito em C# como projeto de aprendizagem.

## Funcionalidades
- Ver tarefas
- Adicionar tarefas
- Remover tarefas

## Como correr
1. Instala o .NET SDK
2. Clona o repositório
3. Corre `dotnet run` na pasta do projeto

## Tecnologias
- C# / .NET
